# Work Winning

A clean, minimal website for a B2B proposal writing consultancy.
Built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies.

## Overview

Work Winning is a Vancouver-based consultancy that helps infrastructure
and construction companies win contracts through expert proposal writing,
editing, and design. This site serves as their public portfolio and
point of contact.
## Local preview

No build step is required. Clone the repository and serve the project directory with any static file server. For example:

```bash
python -m http.server 8080
```

Then open [http://localhost:8080](http://localhost:8080). Using a local server instead of opening `index.html` directly keeps browser behavior consistent for relative assets and JavaScript.

## Project scope

The repository intentionally keeps the implementation lightweight:

- semantic HTML for content and structure
- CSS for responsive presentation
- JavaScript for interactive behavior
- no package installation or framework-specific tooling
